 [1] 공통 구분자
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- [HAND] ... : GhostFilter 관련 디버그 라인

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 [2] Step 3.5 (손 가림/환각 억제) 변수
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- verdict: KEEP / OCCLUDED / SKIP
  
  ✅ KEEP: 정상 손으로 판단, 레이어 0 (정상)
  
  🟡 OCCLUDED: 가려진/환각으로 판단, -1 레이어 (occluded_indices에 마킹)
      → 제거되지 않음! score는 유지됨
      → 렌더링 시 점선/투명도로 표현 가능
  
  ⚪ SKIP: gating(사전 조건) 실패로 Step3.5 자체를 실행하지 않음
      예: wrist_score < 0.3 또는 active < min_pts

- thr: hand_finger_min_confidence (손 키포인트가 'active'로 집계되기 위한 최소 confidence)
- active=N/21: confidence >= thr 인 손 키포인트 개수
- min_pts: Step3.5 평가를 수행하기 위한 최소 active 개수
- wrist_score / elbow_score: 바디 키포인트(손목/팔꿈치) confidence (gating 및 스케일 추정에 사용)
- forearm: 팔꿈치-손목 거리 (현재 이미지 좌표계 픽셀 단위)
- base_r: 손목 중심 원 반지름(near 판정에 사용)
  - base_r = max(min_radius, forearm * radius_ratio)
- near: active 점 중 distance(wrist, point) <= base_r 인 점 개수
- near_ratio: near / active
- min_near: 통과에 필요한 최소 near_ratio (hand_min_near_ratio)
- far_r: far outlier 원 반지름 (far_r = base_r * far_ratio)
- far: active 점 중 distance >= far_r 인 점 개수
- max_far: 허용 가능한 far outlier 최대 개수 (hand_max_far_points)
- farthest(active): 가장 멀리 있는 active 점 상위 목록 (idx<k>:d=<거리>,c=<confidence>)

 [3] 레이어 시스템
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
레이어 0 (정상): 이미지 안에서 정상적으로 보이는 키포인트
레이어 -1 (가려짐): 이미지 안에 있지만 옷/신체에 가려진 키포인트
                   → occluded_indices에 마킹됨
                   → score는 유지됨 (제거 안 됨!)
레이어 -2 (프레임 밖): 이미지 경계 밖으로 나간 키포인트
                      → out_of_frame_indices에 마킹됨
                      → 렌더링 시 포인트(원)는 안 그리고 라인만 그림

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 [4] 제거 사유 (removal_reasons)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- dummy_no_parent: 더미 좌표 + 부모 관절 없음 → 완전 제거
- boundary_val: DWPose 감지 실패로 경계값(0, 0)에 찍힌 더미 → 제거
- clustered_hand: 손 점들이 비정상적으로 한 점에 뭉침 (오검출) → 제거
- orphan_node: 부모 관절이 제거되어 연쇄 제거됨 (Chain Kill) → 제거
- occluded_LHand/RHand(마킹만): 가려진 것으로 판단 → -1 레이어 마킹 (제거 안 됨!)
